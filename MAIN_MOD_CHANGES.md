# Project Flint Main-Mod Changes — Flint Quests v0.1.22-a

## Required Project Flint changes for this patch

**None.**

v0.1.22-a is entirely internal to Flint Quests. Project Flint can remain completely untouched.

## What changed inside Flint Quests

- quest-data ZIP import now uses a native file picker and continues to validate the Flint Quests manifest/schema before import;
- built-in themes use translucent UI surfaces;
- the last opened quest category is remembered;
- the Rules tab can explicitly require quests from any category;
- settings layout spacing was cleaned up.

None of these features require Project Flint API hooks.
